The application extracts document content, divides long PDFs into chunks, retrieves relevant sections and generates context-based answers without requiring a paid cloud AI API.

**Tech:** `Python` `PyPDF` `Ollama` `Qwen3 8B` `Local LLMs`

**Highlights:** 🔒 Local processing • 🧩 Document chunking • 🔎 Context retrieval • 💰 No paid API required
